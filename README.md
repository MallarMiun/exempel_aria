# Skärmläsare och ARIA

Ett enkelt demo-projekt för att visa hur ARIA och semantisk HTML påverkar upplevelsen för användare med skärmläsare.

Projektet innehåller två versioner av samma sida:

- `utan-aria.html` – exempel där visuell funktionalitet finns, men viktig information inte alltid förmedlas till hjälpmedel.
- `med-aria.html` – samma exempel kompletterade med semantisk HTML och ARIA.

Exemplen visar bland annat:

- `aria-expanded` och `aria-controls`
- `aria-label`
- `aria-live`
- `aria-invalid`
- `aria-describedby`
- skillnaden mellan `placeholder` och `<label>`

Testa gärna båda sidorna med en skärmläsare och jämför hur samma gränssnitt upplevs. Det kan skilja sig beroende vad för skärmläsare man använder.
